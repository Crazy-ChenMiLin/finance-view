🚀 GitHub Pages 自动化构建与持续发布

本平台采用与原业务仓库绝对解耦的架构设计，完全托管于独立 GitHub 仓库，并通过 GitHub Actions 自动化构建并发布到 GitHub Pages。

🌐 GitHub Pages 在线访问地址：
👉 https://crazy-chenmilin.github.io/finance-view/

📄 GitHub Actions 工作流配置 (.github/workflows/living-architecture.yml)：

name: Living Architecture CI/CD

on:
  push:
    branches: [ main ]
  schedule:
    - cron: '0 3,9,15,21 * * *'
  workflow_dispatch:

permissions:
  contents: write
  pages: write
  id-token: write

jobs:
  check-and-deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm install --production=false
      - run: node scripts/build-site.js
      - run: node -e "require('./scripts/security-sanitizer').sanitizeAndVerifyDirectory('./dist')"
      - uses: actions/configure-pages@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      - uses: actions/deploy-pages@v4

🛡️ 核心合规与架构隔离保障：

  • 双库严格解耦：公司核心业务仓库（finance）保持 100% 原始纯净，禁止混入任何外部 CI、文档生成脚本或临时文件。
  • 零凭据泄露 (Zero Credential Leak)：内置 security-sanitizer.js 自动脱敏内部服务器 IP、数据库明文密码及内部 Token。
  • 只读 AST 架构抽取：通过独立扫描器以纯只读方式挂载历史 Commit 结构，动态提取业务链路拓扑。
  • 本地即时预览：已启动专属轻量服务 http://localhost:8088，开箱即用。
